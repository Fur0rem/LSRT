§Link Stream Robustness Tool

This is a tool to calculate the robustness of a network to a series of attacks. The network is represented as a graph, and the attacks are represented as a series of edges that are removed from the graph. The tool can calculate the robustness of the network to a series of attacks, and output the results in a file. The two units measured are the efficiency and the reachables. The efficiency is the average shortest path length between all pairs of nodes in the network. The reachables is the number of nodes that are reachable from all other nodes in the network.

Each attack containts a set of blocked links, and has a delta and a max tick. The max tick is the maximum tick the attack can last, which is the diameter of the network. The delta is the number of simulation ticks between each step of the attack. So with a delta of 4, if a link is not blocked at time 0, and blocked at time 1, it will be not blocked at ticks 0, 1, 2, 3, and blocked at ticks 4, 5, 6, 7.

The tool can measure those using two modes, which affects when you can cross a link of weight N at tick t:

  1. Default : If the link isn’t blocked at tick t, you can cross it.
  2. Aggressive : The link needs to not be blocked from tick t to t + N to be crossed.

Type Aliases§

  • Node
    A Node in the graph. Paris has 9596 nodes, so u16 should be enough
  • Tick
    A Tick is a unit of time in the graph, it represents one step in the simulation. Paris has a diameter of 1404 ticks, so u16 should be enough. A tick of 0 or Tick::MAX represents an infinite weight, or a removed edge.
  • Time
    A Time is a unit of time in the graph, it represents one step in the attack. Each attack has a delta, which is the number of ticks for one time. So Time <= Tick
