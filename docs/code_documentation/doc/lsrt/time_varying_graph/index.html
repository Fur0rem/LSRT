Structs

  • PhantomEdge
    A phantom edge is used to replace a blocked edge with an edge with an equivalent weight + waiting time This allows us to remove the time dimension from the graph, and use classical algorithms on it The weight of the edge is now a vector of weights, where we can index the weight by the time
  • TimeVaryingGraph
    The TimeVaryingGraph is a graph where the edges can be blocked at certain times The graph is represented as an adjacency list, where each edge is a PhantomEdge
